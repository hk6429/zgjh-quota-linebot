## 📊 Google 試算表雲端大腦（7 大核心工作表架構）

本專案採用 **Google 試算表 (Google Sheets) 作為零快取 RAG 知識庫**，註冊組同仁隨時在試算表修改文字或新增問答，LINE 機器人 1 秒內即時同步生效：

| 工作表名稱 | 核心功能說明 | 欄位結構摘要 |
| :--- | :--- | :--- |
| **1. 總量管制Q&A知識庫** | LINE Bot 即時比對題庫（20 組官方問答＋#記住 新增列） | 編號、主題分類、關鍵字、家長問題、標準回覆、法規依據、啟用狀態 |
| **2. 六大順位判定矩陣** | 第 1 順位至最後順位審查標準 | 順位代碼、順位名稱、適用身分、戶籍要件、居住證明、家訪要求、排序規則 |
| **3. 學區劃分與改分發學校** | 單一學區 vs 共同學區完整對照表 | 項次、學區類別、里別、鄰別、共同學區、改分發學校、115異動備註 |
| **4. 115學年度重要日程表** | 17 項重大時程（說明會至測驗） | 項次、作業項目、法定時程、地點/管道、承辦單位、重要要點 |
| **5. 歷年設籍門檻數據** | 111～114 學年第四順位設籍門檻 | 學年度、核定班級數、錄取順位、設籍門檻年限、約當就讀年級、分析說明 |
| **6. 家長在線提問紀錄簿** | LINE 輸入 `#提問` 自動立案登記 | 提問時間、諮詢單號、家長LINE識別碼、畢業國小、提問內容、處理狀態 |
| **7. 待補充問題庫** | AI 自動收集特殊或未命中提問 | 收集時間、原句提問、觸發模式、提問者ID、頻次、建議處室、擬定答案 |

💡 **已產生之實體試算表檔案**：
- 雲端硬碟位置：`.../116 資訊組/03 領域/總量管制相關資料/竹光國中115學年度總量管制知識庫.xlsx`
- 專案程式碼中亦內建 `initQuotaKnowledgeBaseSheet()` 函式，在空白試算表中執行即可 1 秒自動建立全部 7 大工作表！

## 🌟 雙核心設計架構與痛點解方

每年 3 月國中新生登記事前，國中小學端總面臨巨大溝通壓力：
- 家長焦慮：「我家住 XX 里算不算學區？」、「租房子沒有去法院公證能不能登記？排第幾順位？」、「設籍滿三年排不排得上？」、「黃單要帶什麼證件？」、「如果沒錄取會被分發去哪裡？」
- 註冊組負擔：總機電話響不停、重複解答同一問題、資格審查現場面對非親屬同戶、中途遷出設籍累計、雙胞胎抽籤等爭議法規。

本專案將竹光國中 115 學年度最新總量限制入學作業規定、Q&A 與說明會簡報，轉化為 **24 小時在線的雙核心智慧小幫手**：

### 👨‍👩‍👧 模組 A：【家長篇 · 入學資格試算與流程導引】
1. **六大順位智慧試算**：輸入房屋自有、租屋公證/未公證、戶籍設籍狀況，秒算錄取順位與必備證件。
2. **歷年錄取年份大數據**：公開 111-114 學年度第四順位設籍門檻（111年設籍5年、112年設籍4年、113年設籍8年、114年設籍2年），協助家長建立合理心理預期。
3. **設籍累計規則解析**：清楚說明「學區內搬家可連續累計」與「中途曾遷出學區重頭起算」之法規標準。
4. **3/14 (六) 現場登記應備清單**：新生通知單（黃單）、戶籍謄本正本或詳細記事戶口名簿、居住證明文件一次備齊。

---

### 🏛️ 模組 B：【註冊組篇 · 法規審核與行政處置指引】
1. **爭議案例審查 SOP**：非親屬同戶居住事實查核、家訪同意書簽具標準、未簽同意書列為第六順位並勸導轉學。
2. **同日遷入與多胞胎規定**：同日設籍以有兄姊就讀優先，條件相同公開抽籤；多胞胎一人錄取手足外加名額保障。
3. **共同學區雙重登記手續**：北門里（115新增）、新雅里19鄰若欲同時登記另一所總量學校，須於 3/12 前向另一校提出申請。
4. **未錄取改分發追蹤**：單一學區改分發虎林、成德、光華、育賢、建華國中；4/17 前統一函送名冊，4/20 前改分發國中寄送通知單。

## 🎯 竹光國中 115 學年度錄取六大順位階層

> 排序基本原則：**先比順位，同順位再依「戶籍遷入學區時間先後」排序**。最後一名同日遷入者，以有兄姊在校者優先，條件仍相同者公開抽籤。

| 順位 | 對象與資格要求 | 居住證明要件 | 備註 |
| :--- | :--- | :--- | :--- |
| **第一順位** | 少年保護安置、低收入戶、父母雙亡、編制內教職員工隨同子女、市府鑑定安置資源生 | 依市府核定公文或列冊證明 | 實地查核居住事實 |
| **第二順位** | 設籍本校學區之**本市國小畢業生**，與直系尊親屬同戶 | **自有權狀** / 115房屋稅籍證明 或 **法院公證租約** | 租期涵蓋 115/3/14~9/1 |
| **第三順位** | 設籍本校學區之**外縣市國小畢業生**，與直系尊親屬同戶 | **自有權狀** / 115房屋稅籍證明 或 **法院公證租約** | 租期涵蓋 115/3/14~9/1 |
| **第四順位** | 設籍本校學區之國小畢業生，與直系尊親屬同戶 | 僅提供**未經法院公證之租賃契約** | 租期涵蓋 115/3/14~9/1 |
| **第五順位** | 設籍本校學區之國小畢業生，與直系尊親屬同戶 | **無法提供居住證明文件**（或文件不符規定） | 簽具家訪同意書 |
| **第六順位（最後順位）** | 符合入學資格，但**無法簽具家訪同意書**，或經查為空戶／非實際居住者 | - | 空戶者勸導轉入實際居住學區學校 |

> ⚠️ 戶籍內**沒有直系尊親屬同戶**者，**無法參加新生登記**，連順位都沒有（不是第六順位）。

## 🚀 10 分鐘極速部署教學

### 步驟一：建立 LINE Messaging API 頻道
1. 登入 [LINE Developers 後台](https://developers.line.biz/console/)。
2. 建立 Provider 並新增 **Messaging API Channel**。
3. 取得 **Channel Access Token**（點擊 Issue）。
4. 在 Channel 設定中將「自動回應訊息 (Auto-reply messages)」關閉，並確保「Webhook」開啟。

### 步驟二：貼入 Apps Script 核心代碼
1. 開啟空白 [Google 試算表](https://sheets.new)。
2. 點選上方選單「擴充功能」➔「Apps Script」。
3. 將本專案中的 `Code.gs` 複製並覆蓋貼上。
4. 在上方選單選取 `initQuotaKnowledgeBaseSheet` 並執行，試算表將自動灌入 7 大工作表（Q&A 20 題、順位矩陣、學區、日程、歷年門檻）。重跑會保留同仁用 `#記住` 新增的列，不會清掉。
5. 填入您的 `LINE_ACCESS_TOKEN` 與 Google AI Studio 取得的 `GEMINI_API_KEY`（未填時，知識庫沒命中的問題會回引導選單並記入「待補充問題庫」）。
6. **更新既有部署時**：貼上新版 `Code.gs` 後，須到「部署」➔「管理部署作業」➔ 編輯 ➔ 版本選「新版本」再部署，Webhook 才會吃到新程式。

### 步驟三：發布 Webhook 上線
1. 點擊右上角「部署 (Deploy)」➔「新增部署作業 (New deployment)」。
2. 類型選擇「網頁應用程式 (Web App)」。
3. 執行身分選擇「我」，誰可以存取選擇「**所有人 (Anyone)**」。
4. 點擊部署，將產生的 **Web App URL** 複製貼回 LINE Developers 的 Webhook URL 欄位並點擊 Verify 驗證！

## 🧠 知識庫單一資料源與比對引擎

所有問答內容只維護一份 `knowledge_base.json`，跑 `python3 build_site.py` 會同步灌進三處：

| 目的地 | 內容 |
| :--- | :--- |
| `Code.gs` | `KB_SEED`（initQuotaKnowledgeBaseSheet 種子）＋ `kb_matcher.js` 共用比對引擎 |
| `index.html` | LINE 模擬器直接用同一份 Q&A 與引擎，網頁回答＝正式 bot 回答 |
| `.xlsx` | `python3 create_sheets_db.py` 產出 7 大工作表 Excel（雲端硬碟＋專案目錄各一份） |

**觸發關鍵字欄語法**（試算表 C 欄，註冊組可直接改）：

- `沒有租約,五順位`：逗號分隔，句子包含任一詞即得分，**分數＝詞長**（越長越專屬，最高分勝出）
- `差別+順位`：兩詞都出現才算命中
- `-未公證`：句子出現此詞就整列排除（例：「公證租約」列排除「未公證」，避免答成第二順位）
- 完全沒命中但句子含「順位」→ 回「順位總覽」列；仍沒命中 → Gemini（若設定）→ 引導選單並記入待補充問題庫

驗證：`node test_matcher.js`（28 句家長真實問法，含「沒有租約算第幾順位」「第四跟第五順位差別」等）。

## 📄 專案目錄結構

```
zgjh-quota-linebot/
├── knowledge_base.json  # ★ 單一資料源：20 題 Q&A、順位矩陣、學區、日程、歷年門檻

├── README.md            # 專案說明與法規手冊
```
